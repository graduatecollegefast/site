# GraduateCollegeFast Website

Static site. No build step. Deploys as-is.

## To change a link or price

All links live in `config.js`. Edit that file only.
Prices live in `offers.html`.

## Deploy

Connected to Netlify. Pushing to `main` publishes the site.

## Forms

- Contact form: Netlify Forms. Submissions appear in the Netlify dashboard.
- Email opt-in: posts to Kit form 9230406.
